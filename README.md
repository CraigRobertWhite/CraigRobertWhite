## What I'm up to

### 🎴 Training a machine learning model to play Magic: The Gathering

![Django](https://img.shields.io/badge/Django-092E20?logo=django&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white)
![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?logo=pytorch&logoColor=white)

I was pretty interested in learning about machine learning, and I figured what better way to rationalize raising my electricity bill than training something to help me play and build my decks.

There's this really cool, unofficial rules engine called [Forge](https://github.com/Card-Forge/forge). I built a Django REST API that handles the model side of things, so Forge can relay what's happening in a game and ask what the model would do when it's given a choice. MTG is a pretty complicated game, and while I've got the entity transformer built and matching Forge's "AI" decisions with around 97% accuracy on my current evaluation set, I've still got a ton of work cut out for me as I move into self-training.

I've got a lot of ideas for what I could eventually do with the project and all of the data, but for now it's mostly a fun excuse to play with machine learning and see where it goes.

### 🧙‍♂️ Building an AI text adventure game

![Anthropic API](https://img.shields.io/badge/Anthropic%20API-D97757?logo=claude&logoColor=white)
![Django](https://img.shields.io/badge/Django-092E20?logo=django&logoColor=white)
![Pydantic](https://img.shields.io/badge/Pydantic-E92063?logo=Pydantic&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)
![Vue.js](https://img.shields.io/badge/Vue.js-4FC08D?logo=vuedotjs&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-%2338B2AC.svg?logo=tailwind-css&logoColor=white)

You provide the source material for a story you're interested in, it gets broken down into something the game can work with, then you and your friends role-play as new or existing characters and live through it.

It uses vector search to pull in relevant pieces of the original story, persistent game state and a knowledge graph to remember what's happened between characters and locations, and the Anthropic API to tie it all together and act as the DM.

Think [AI Dungeon](https://aidungeon.com/), but with persistent world state, source material, and a lot more structure around what the AI is allowed to do.
